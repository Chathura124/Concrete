# Concrete — DeFi Explained

A responsive, single-page educational website about Concrete.

## Included
- Concrete-inspired yellow / charcoal visual system
- Moai-inspired hero illustration built with CSS (no external image dependency)
- Light / dark mode with localStorage
- Responsive mobile layout
- Sections covering:
  - What Concrete is
  - ERC-4626 vaults
  - Deposit → strategy → yield flow
  - Vault shares / ct[asset]
  - Security model
  - Risks
  - Blog / research links
  - Official links
- Links to Concrete's official website, app, docs, points, X and Paragraph posts
- External Halborn audit link

## Run
Open `index.html` directly in a browser, or serve the folder with a local development server.

## Important
This is an independent educational interface, not the official Concrete website. Product data and descriptions can change. Always verify current information against Concrete's official docs and app before making financial decisions.
