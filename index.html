01 / THE IDEA

So, what exactly is Concrete?

Concrete is DeFi infrastructure designed to automate yield generation through vaults. Instead of manually moving capital between lending markets, staking opportunities and other strategies, a user can deposit into a vault and receive yield-bearing vault shares.

The current product is built around ERC-4626 vaults. Concrete's technology stack handles allocation between strategies, accounting updates and withdrawal processing, while users interact primarily with the vault.

01

Deposit once

Put a supported asset into a selected Concrete vault instead of managing several underlying positions yourself.

02

Strategies work

Capital can be allocated across vetted on-chain strategies such as lending, staking or liquidity opportunities.

03

Receive shares

You receive ERC-20 vault shares such as ctWBTC. Yield is reflected through the vault's exchange rate.

03 / VAULTS

Vaults are the
building blocks.

Concrete describes its vaults as a way to package DeFi strategies into a simpler user experience. Vault shares are tokenized, which means the position can become useful elsewhere in the ecosystem.

Concrete's public materials also describe ecosystem-specific and institutional vault products, with strategy allocation handled behind the vault interface.

04 / SECURITY

Understand the guardrails.

Concrete's docs describe a layered security model. Audits reduce some classes of risk, but they do not make DeFi risk-free.

Read official docs ↗
01

Separated roles

Governance roles such as Vault Manager, Strategy Manager and Hook Manager are separated from automated operational roles.

02

Custody controls

Docs describe deposits being forwarded to a MultisigStrategy backed by Gnosis Safe or Fordefi MPC wallets.

03

Bounded accounting

Accounting updates are constrained by thresholds, cooldowns and validity windows.

04

Independent monitoring

Concrete documents Blockaid monitoring for real-time risk detection and a pre-delegated pause authority.

05

Multiple reviews

The docs list security work involving Halborn, Cantina, Zellic and Code4rena, with each review covering a defined scope/version.

06

Risk still exists

Concrete explicitly states that yields are not guaranteed and strategy losses can reduce share value, including possible loss of deposited assets.
